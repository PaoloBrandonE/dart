5. FASE 1: CLASE TAREA

Una clase describe los datos y comportamientos de un tipo de objeto. Cada tarea registrada es una instancia de Tarea o de su subclase.

Atributos:
  String titulo: texto obligatorio que identifica lo que se debe hacer.
  bool completada: indica el estado; comienza en false.
  String? categoria: clasificación opcional; puede ser null.

Constructor:
  Tarea({required this.titulo, this.categoria, this.completada = false});

Usa parámetros nombrados. required obliga a proporcionar titulo al construir el objeto. No comprueba por sí mismo que el título no esté vacío: esa validación se realiza en las funciones de registro.

Getter marca:
  String get marca => completada ? '[X]' : '[ ]';

Es una propiedad calculada a partir del estado. El operador ternario selecciona una de las dos marcas.

Método descripcion(): devuelve una cadena con la marca, el título y la categoría. Si categoria es null, usa 'Sin categoria' mediante ??.

6. FASE 2: HERENCIA Y POLIMORFISMO

Relación:
  Tarea (clase base)
    |
    +-- TareaConVencimiento (subclase)
          añade String fechaVencimiento
          sobrescribe descripcion()

La declaración 'class TareaConVencimiento extends Tarea' expresa que una tarea con vencimiento también es una tarea. Comparte título, categoría, estado, getter y comportamiento de la clase base.

extends: establece la relación de herencia.
super(titulo: titulo, categoria: categoria): llama al constructor de la clase base. El estado completada utiliza su valor inicial false.
@override: indica que la subclase sobrescribe un método heredado.
super.descripcion(): reutiliza la descripción base y permite añadir la fecha sin repetir la construcción del resto del texto.

La fecha se conserva como String, según el diseño de la guía. DateTime se usa solo para comprobar si la fecha ingresada existe.

Ejemplo de polimorfismo: List<Tarea> contiene tareas simples y tareas con vencimiento. Al llamar tareas[i].descripcion(), se ejecuta la implementación correspondiente al objeto real. No es necesario preguntar por su tipo para mostrarlo.

Los atributos son públicos y el programa no implementa campos privados. No afirmar que utiliza encapsulamiento mediante getters y setters privados, clases abstractas o interfaces explícitas.

7. FASE 3: LISTA, REGISTRO Y CONSULTA

Colección principal:
  List<Tarea> tareas = [];

La lista guarda objetos, no solo títulos. Su tipo permite utilizar los atributos y métodos de Tarea, y también almacenar instancias de TareaConVencimiento.

agregarTarea(): lee el título, rechaza texto vacío, pide categoría y crea el objeto. Una categoría vacía se convierte en null. Finalmente utiliza tareas.add().

agregarTareaConVencimiento(): realiza las mismas lecturas y solicita una fecha. Si la fecha es válida crea la subclase y la agrega a la lista. Esta es la función que el ejemplo de la guía deja por desarrollar.

listarTareas(): informa si la lista está vacía. Si hay datos, usa un for con índice y muestra i + 1 para numerar desde 1. La lista internamente empieza en el índice 0.

leerTexto(String mensaje): centraliza la pregunta y la lectura. Devuelve String? y elimina espacios de los extremos con trim().

8. FASE 4: COMPLETAR Y ELIMINAR

pedirIndice(String accion) devuelve int?. Primero comprueba si existen tareas, muestra la lista y pide un número.

int.tryParse(entrada) intenta convertir el texto en entero. Si el usuario escribe letras, devuelve null en lugar de lanzar una excepción de conversión.

Se acepta solo un número entre 1 y tareas.length. El índice devuelto es numero - 1. De esta forma se evita acceder fuera de la lista.

completarTarea(): obtiene el índice y cambia completada a true. Si ya estaba completada, informa al usuario sin volver a modificarla.

eliminarTarea(): obtiene el índice y llama a tareas.removeAt(indice). Este método devuelve el objeto eliminado, cuyo título se muestra como confirmación. La numeración se actualiza al listar de nuevo.

9. FASE 5: ESTADÍSTICAS CON MAP

Estructuras y variables:
  int completadas = 0;
  Map<String, int> porCategoria = {};

El mapa relaciona el nombre de una categoría (String) con su cantidad de tareas (int). Se crea antes del bucle para acumular los conteos de toda la lista.

Se recorre la lista con for (Tarea tarea in tareas). Si una tarea está completada, se incrementa el contador. También se obtiene su categoría, usando 'Sin categoria' cuando es null.

Línea clave:
  porCategoria[categoria] = (porCategoria[categoria] ?? 0) + 1;

Si la clave aún no existe, la consulta devuelve null y ?? lo reemplaza por cero. Luego se suma uno. Si ya existe, se incrementa su cantidad anterior.

Total = tareas.length.
Pendientes = total - completadas.
El conteo por categoría incluye tanto tareas pendientes como completadas.
forEach recorre las entradas del mapa para mostrarlas.

10. FASE 6: MENÚ Y FLUJO PRINCIPAL

mostrarMenu() imprime las opciones. main() mantiene un bool ejecutando inicialmente true y repite un while mientras ese valor siga activo.

El switch selecciona la función según la opción ingresada. default muestra un aviso si la opción no existe. Al elegir 0 se asigna false a ejecutando y finaliza el bucle.

Los break dentro de los casos terminan el switch. El break usado ante una entrada null está directamente dentro del while y termina ese bucle.

Flujo para un diagrama:
  Inicio -> Mostrar menú -> Leer opción
  Entrada null -> Avisar fin de entrada -> Fin
  Opción 0 -> Despedida -> Fin
  Opción 1 a 6 -> Ejecutar función -> Volver al menú
  Otra opción -> Mostrar aviso -> Volver al menú

11. NULL SAFETY Y VALIDACIONES

String? categoria: admite ausencia de clasificación.
String? de leerTexto(): permite detectar que la entrada se cerró.
int? de pedirIndice(): permite indicar que no existe un índice válido.
?.trim(): solo aplica trim si la lectura no fue null.
??: proporciona un valor alternativo para categoría y para conteos nuevos.
required: exige pasar ciertos argumentos al constructor.
return temprano: detiene una operación cuando hay un dato inválido.

Una línea vacía y null son situaciones distintas. Enter puede producir una cadena vacía: se rechaza para el título y se acepta para omitir la categoría. null indica fin de entrada; la operación se cancela y el menú finaliza al detectarlo.

Validación de fecha:
  1. RegExp comprueba exactamente dos dígitos de día, dos de mes y cuatro de año, separados por '/'.
  2. split('/') separa las tres partes.
  3. int.parse convierte partes cuyo formato numérico ya fue comprobado.
  4. Se rechaza el año cero.
  5. DateTime construye una fecha y se comparan día, mes y año con los originales.

La comparación es necesaria porque DateTime normaliza valores fuera de rango. Por ejemplo, un día imposible de febrero puede pasar al mes siguiente. Se admiten fechas pasadas, porque la aplicación no exige fechas futuras.

17. PREGUNTAS PARA PREPARAR LA EXPOSICIÓN

¿Por qué categoria es String? y titulo es String?
Porque la clasificación puede omitirse, pero toda tarea necesita un título. Además de required, se valida que no esté vacío.

¿Qué se reutiliza con la herencia?
Los atributos y el comportamiento de Tarea; la subclase agrega la fecha y amplía descripcion().

¿Por qué la lista acepta los dos tipos?
Porque TareaConVencimiento es una subclase de Tarea.

¿Por qué usar tryParse para seleccionar una tarea?
Porque una entrada no numérica devuelve null y puede manejarse sin una excepción.

¿Por qué restar uno al número elegido?
Porque la numeración visible empieza en 1 y los índices de List empiezan en 0.

¿Qué hace el Map?
Asocia cada categoría con el número de tareas que pertenecen a ella.

¿Qué ocurre al cerrar el programa?
Termina la sesión y se pierden las tareas, ya que solo estaban en memoria.

===== INICIO DEL CÓDIGO DART =====

import 'dart:io';

// Fase 1: datos de una tarea.
class Tarea {
  String titulo;
  bool completada;
  String? categoria;

  Tarea({required this.titulo, this.categoria, this.completada = false});

  String get marca => completada ? '[X]' : '[ ]';

  String descripcion() {
    // Si no se escribio una categoria, mostramos este texto.
    String cat = categoria ?? 'Sin categoria';
    return '$marca $titulo  ($cat)';
  }
}

// Fase 2: esta tarea tambien tiene una fecha limite.
class TareaConVencimiento extends Tarea {
  String fechaVencimiento;

  TareaConVencimiento({
    required String titulo,
    required this.fechaVencimiento,
    String? categoria,
  }) : super(titulo: titulo, categoria: categoria);

  @override
  String descripcion() {
    // Aprovechamos la descripcion de Tarea y agregamos la fecha.
    return '${super.descripcion()}  vence: $fechaVencimiento';
  }
}

// Fase 3: guardar, agregar y listar las tareas.
List<Tarea> tareas = [];

String? leerTexto(String mensaje) {
  stdout.write(mensaje);
  return stdin.readLineSync()?.trim();
}

void agregarTarea() {
  String? titulo = leerTexto('Titulo de la tarea: ');
  if (titulo == null) return;
  if (titulo.isEmpty) {
    print('El titulo no puede estar vacio.');
    return;
  }
  String? entrada = leerTexto('Categoria (Enter para omitir): ');
  if (entrada == null) return;
  String? categoria = entrada.isEmpty ? null : entrada;
  tareas.add(Tarea(titulo: titulo, categoria: categoria));
  print('Tarea agregada correctamente.');
}

bool fechaValida(String fecha) {
  if (!RegExp(r'^\d{2}/\d{2}/\d{4}$').hasMatch(fecha)) return false;
  List<String> partes = fecha.split('/');
  int dia = int.parse(partes[0]);
  int mes = int.parse(partes[1]);
  int anio = int.parse(partes[2]);
  if (anio < 1) return false;
  DateTime comprobacion = DateTime(anio, mes, dia);
  // DateTime ajusta fechas como 31/02; por eso comparamos sus partes.
  return comprobacion.day == dia &&
      comprobacion.month == mes &&
      comprobacion.year == anio;
}

void agregarTareaConVencimiento() {
  String? titulo = leerTexto('Titulo de la tarea: ');
  if (titulo == null) return;
  if (titulo.isEmpty) {
    print('El titulo no puede estar vacio.');
    return;
  }
  String? entrada = leerTexto('Categoria (Enter para omitir): ');
  if (entrada == null) return;
  String? categoria = entrada.isEmpty ? null : entrada;
  String? fecha = leerTexto('Fecha de vencimiento (dd/mm/aaaa): ');
  if (fecha == null) return;
  if (!fechaValida(fecha)) {
    print('Fecha invalida. Usa dd/mm/aaaa y una fecha que exista.');
    return;
  }
  tareas.add(TareaConVencimiento(
    titulo: titulo,
    categoria: categoria,
    fechaVencimiento: fecha,
  ));
  print('Tarea con vencimiento agregada correctamente.');
}

void listarTareas() {
  if (tareas.isEmpty) {
    print('No hay tareas registradas.');
    return;
  }
  print('--- LISTA DE TAREAS (${tareas.length}) ---');
  for (int i = 0; i < tareas.length; i++) {
    print('[${i + 1}] ${tareas[i].descripcion()}');
  }
}

// Fase 4: completar y eliminar usando el numero de la lista.
int? pedirIndice(String accion) {
  if (tareas.isEmpty) {
    print('No hay tareas para $accion.');
    return null;
  }
  listarTareas();
  String? entrada = leerTexto('Numero de la tarea a $accion: ');
  if (entrada == null) return null;
  int? numero = int.tryParse(entrada);
  if (numero == null || numero < 1 || numero > tareas.length) {
    print('Numero invalido.');
    return null;
  }
  // La numeracion empieza en 1, pero los indices empiezan en 0.
  return numero - 1;
}

void completarTarea() {
  int? indice = pedirIndice('completar');
  if (indice == null) return;
  if (tareas[indice].completada) {
    print('La tarea ya estaba completada.');
    return;
  }
  tareas[indice].completada = true;
  print('Tarea marcada como completada.');
}

void eliminarTarea() {
  int? indice = pedirIndice('eliminar');
  if (indice == null) return;
  Tarea eliminada = tareas.removeAt(indice);
  print('Se elimino: ${eliminada.titulo}');
}

// Fase 5: contar las tareas y agruparlas por categoria.
void verEstadisticas() {
  int completadas = 0;
  Map<String, int> porCategoria = {};
  for (Tarea tarea in tareas) {
    if (tarea.completada) completadas++;
    String categoria = tarea.categoria ?? 'Sin categoria';
    // Una categoria nueva empieza con cero antes de sumar.
    porCategoria[categoria] = (porCategoria[categoria] ?? 0) + 1;
  }
  print('--- ESTADISTICAS ---');
  print('Total de tareas : ${tareas.length}');
  print('Completadas     : $completadas');
  print('Pendientes      : ${tareas.length - completadas}');
  print('Por categoria:');
  if (porCategoria.isEmpty) print('  No hay categorias registradas.');
  porCategoria.forEach((categoria, cantidad) {
    print('  $categoria: $cantidad');
  });
}

// Fase 6: repetir el menu hasta elegir salir.
void mostrarMenu() {
  print('');
  print('===== GESTOR DE TAREAS =====');
  print('1. Agregar tarea');
  print('2. Agregar tarea con vencimiento');
  print('3. Ver tareas');
  print('4. Marcar como completada');
  print('5. Eliminar tarea');
  print('6. Ver estadisticas');
  print('0. Salir');
}

void main() {
  bool ejecutando = true;
  while (ejecutando) {
    mostrarMenu();
    String? opcion = leerTexto('Elige una opcion: ');
    // Si se cierra la entrada, salimos sin repetir el menu para siempre.
    if (opcion == null) {
      print('Fin de la entrada. Hasta pronto.');
      break;
    }
    switch (opcion) {
      case '1':
        agregarTarea();
        break;
      case '2':
        agregarTareaConVencimiento();
        break;
      case '3':
        listarTareas();
        break;
      case '4':
        completarTarea();
        break;
      case '5':
        eliminarTarea();
        break;
      case '6':
        verEstadisticas();
        break;
      case '0':
        ejecutando = false;
        print('Hasta pronto.');
        break;
      default:
        print('Opcion no valida, intenta de nuevo.');
    }
  }
}
